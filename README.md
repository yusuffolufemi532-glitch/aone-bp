# AONE BP

A WhatsApp business partner for Nigerian salons and vendors. Built solo for the Meta Global AI Developer Hackathon (Indie track).

Status: building, Oct 27 to Nov 4, 2026.

## Goal
- Reply to customers in the owner's tone.
- Enforce the owner's rules (price floors, discount limits) in plain code, never with the model.
- Wait for the owner's approval before any reply is sent.

## Existing before the hackathon
An earlier design prototype with sample data, with no AI and no backend. None of its code or history is in this repository.

## Built during the hackathon
Everything in this repository was written during the hackathon, from Oct 27, 2026.
